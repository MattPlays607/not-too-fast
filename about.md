# Not Too Fast!

Not Too Fast! is a Geometry Dash mod that increases the game speed as you play.

## Features

- Increase game speed after every death or jump-button press.
- Configure the speed increase amount.
- Set a starting speed and maximum speed.
- Optionally keep your speed between levels.
- Display your current speed on screen.
- Reset your speed using a configurable keybind.

## Configuration

All features can be configured through the Geode mod settings.

## Compatibility

Made for Geometry Dash using the Geode mod loader.
